A program that draws one image summing up the world's news of
Wednesday 25 November 2026: 31 stories across 7 regions, each first
reported that day, with sources named beside every story.

Run `python3 draw.py` to render `entry.png` (1024x1024), then
`python3 main.py` copies it to the output directory.
